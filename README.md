# AuraHealth 🧠💙

AuraHealth is a user-focused health management app designed to make personal healthcare effortless through passive data collection, AI insights, and secure data ownership

## 🧩 Key Features
- 📸 Magic Scan (OCR for prescriptions & lab reports)
- 📊 Health trends & visual insights
- 🤖 AI Health Sensei for simple explanations
- 🔐 Smart permission-based data sharing
- ⌚ Wearable & fitness data integration

## 🛠 Tech Stack
- Next.js
- React
- Tailwind CSS
- Vercel

## 🔗 Ecosystem
This app works together with **PulseConnect**, the institutional dashboard used by healthcare providers.
